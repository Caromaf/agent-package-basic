# Maintenance skill evaluation cases

このファイルは `minimal-bugfix` と `converge-codebase` の導入後評価に使う。各ケースでは、実行結果と未検査事項を記録し、Skill 本文の文言一致だけをテストしない。

## minimal-bugfix

- 再現可能な入力境界バグを、秘密値を含まない最小データと回帰テスト付きで修正する。
- 環境依存で再現不能な報告を、推測修正せず追加情報と未解決理由を報告する。
- 既存テスト失敗がある状態で修正し、baseline の失敗と今回の回帰を分けて報告する。

## converge-codebase

- 既存の収束計画を再開し、変更前の違反一覧と test baseline を基準に旧 API から新 API へ段階移行し、呼び出し元を全て切り替えて旧経路を削除する。
- 動的参照と設定参照を含む旧実装を、外部利用の確認と段階検証の後に撤去する。
- 違反総数が減っていても新規違反が追加された場合、全体完了にせず修正対象として残す。
