# `mise-tasks` の評価案

この3件のケースでは、スキルが `mise.toml` を宣言的に保つこと、Windows 専用の file task を安全に扱うこと、任意の `#USAGE` フラグを正しく宣言することを確認します。各 `prompt.md` に初期状態と期待する結果を記載しているため、評価対象リポジトリの状態に依存せず実行できます。

## 実行方法

パッケージのリポジトリで `claude plugin eval --help` を実行し、インストール済み CLI の構文を確認してください。その CLI を使い、このディレクトリ内のケースを `.apm/skills/mise-tasks` にあるスキルと合わせて実行します。CLI のバージョンによってオプション名が異なる場合があります。各ケースは新しい一時リポジトリで実行し、ケースの依頼文に記載した初期状態だけを用意してください。開発用のチェックアウトは使わないでください。

## サンドボックスの前提

- エージェントが読み書きできる範囲は、ケース用の一時リポジトリだけです。実行環境にネットワーク接続や認証情報はありません。
- リリースノートのケースではローカルの Git 履歴だけを使い、GitHub には接続しません。
- CSV のケースでは2つの入力ファイルだけを読み取り、プレビュー件数を表示します。データベースやサービスには接続せず、ファイルも変更しません。
- Windows のケースはソースとファイル配置で評価します。評価ホスト上でタスクを実行したり、ホストのレジストリを読んだりしないでください。別の OS で実行した場合、Windows 上で動作確認したと報告してはいけません。
- 構文、lint、mise のタスク検出は、サンドボックス内で利用できるツールに限って確認してください。実際に行った検査だけを報告してください。
